

\# Group Collaboration Assignment



\## Objective



Build a lightweight collaboration system that allows

multiple human + AI pairs to work together using

Git, GitHub, groupctl, and structured events.



\## Main Components



\- Human students

\- Local AI coding agents

\- Git/GitHub repository

\- groupctl collaboration tool

\- Structured collaboration events



\## Required Commands



\- SYNC

\- PUB

\- INT

\- REV

\- TEST

\- STATUS

\- FINAL



\## Expected Result



One integrated group result on the canonical branch,

supported by code reviews, testing, collaboration

events, and a final report.
